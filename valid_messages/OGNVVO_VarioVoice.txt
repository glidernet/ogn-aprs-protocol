# The following beacons are examples for VarioVoice's APRS format, tocall
# OGNVVO. VarioVoice is an audio only flight instrument for paragliding and
# hang gliding; positions are sent over the internet from the phone.
#
# The ten beacons are one flight in order: two on the ground before the vario
# has settled, where the climb and the turn rate are omitted rather than sent
# as zero; one just airborne; three thermalling, including a pair ten seconds
# apart whose course has reversed and whose position has barely moved; two on
# glide; one hang glider, which differs only in the aircraft type inside the id
# field; and one after landing, still transmitting on the heartbeat.
#
# Each phone logs in with its own callsign and sends only its own position, so
# the packets arrive with a qAC construct and the server that accepted them.
#
# Signal strength, frequency offset and error count are deliberately absent: a
# phone on the internet receives nothing, and reporting 0.0dB 0e +0.0kHz would
# claim a reception that never happened. The climb rate, the turn rate and the
# GPS accuracy are the opposite case, all three measured.
#
# source: https://github.com/glidernet/ogn-aprs-protocol
#
