# The following beacons are examples for XCSoar's APRS format, tocall OGNXCS,
# as the XCSoar Cloud server SENDS them to the APRS server: the client-side qOR
# construct with no callsign after it, which the server rewrites to qAR,XCSOAR
# on the way out.
#
# The first five are a glider with a FLARM address, released from tow and then
# circling in a thermal, one fix every 10 s. The next two are the same glider
# on a glide. The last one is a glider whose FLARM transmits its ICAO address.
#
# Signal strength, frequency offset, error count and turn rate are
# deliberately absent: the Cloud receives nothing over the air, and the fix the
# app sends it does not carry a turn rate.
#
# source: https://github.com/glidernet/ogn-aprs-protocol
#
