# The following beacons are examples of the SkySignals APRS format
# https://skysignals.app - an Android app for paragliding and hang gliding pilots,
# with a SkyCard Radio (FLARM-compatible and FANET radio)
# source: https://github.com/glidernet/ogn-aprs-protocol
#
# These are the sentences the SkySignals backend SENDS over its single APRS-IS
# connection (path ending in qOR). Clients receive them as ...,qAS,SKYSIG:
#
# Source callsign is the aircraft's own radio identity, as an OGN receiver
# reports it: FLR (FLARM address, address type 2), ICA (ICAO address, type 1)
# or FNT (FANET, type 2). The own position uses the pilot's SkyCard Radio address.
#
# Beacons marked RELAY* are FLARM or FANET traffic received by radio by a
# pilot's SkyCard Radio and re-sent under the originating aircraft's identity.
# Nothing is sent for an aircraft OGN already reports from another source.
#
# Ground states use the FANET ground-tracking field FNT7x, the \n symbol and
# aircraft type F, as OGN receivers send them: FNT78 need a ride, FNT79 landed
# well, FNT7D need medical help, FNT7E distress call.
#
# The climb field is omitted when the radio packet carries none. No dB, kHz,
# rot or gps fields are sent.
#
