# The following beacons are examples of the pgpilot APRS format
# https://pgpilot.app - a paragliding flight instrument app
# source: https://github.com/glidernet/ogn-aprs-protocol
#
# Source callsign is PGP + 6 hex. The addresses are app-derived, not
# registered FLARM devices, so the id field carries address type 3 (OGN).
# Aircraft type is 7 (paraglider) or 6 (hang glider).
#
# The climb field is omitted when we do not know it, rather than sent as
# +000fpm. Likewise CSE/SPD is dropped when the fix carries no heading.
# Beacons marked RELAY* are FLARM traffic overheard through one of our
# pilots' devices and re-sent under the originating aircraft's identity.
#
